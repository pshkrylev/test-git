📡 Pereval API

REST API для добавления информации о горных перевалах

Доступные эндпоинты:

  • POST /api/submitData/ - Добавление перевала
  • GET /api/submitData/<id>/ - Получение перевала по ID
  • PATCH /api/submitData/<id>/edit/ - Редактирование перевала
  • GET /api/submitData/?user__email=<email> - Получение перевалов по email

Пример запроса (POST):
